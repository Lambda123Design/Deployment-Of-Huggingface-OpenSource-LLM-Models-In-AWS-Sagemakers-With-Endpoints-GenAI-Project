# Deployment-Of-Huggingface-OpenSource-LLM-Models-In-AWS-Sagemakers-With-Endpoints-GenAI-Project
This Repository contains my working files of "Deployment Of Huggingface OpenSource LLM Models In AWS Sagemakers With Endpoints Projects", an GenAI Project

(i) Set up an AWS SageMaker environment, including creating a single-user domain, configuring IAM roles, and launching a Jupyter Lab workspace for model deployment and testing.

(ii) Prepared the environment by installing the latest SageMaker SDK and required libraries (Boto3, sagemaker).

(iii) Loaded a pre-trained Hugging Face model (distilbert-base-uncased-distilled-squad) and configured it.

(iv) Deployed the model to SageMaker using the deploy() method, tested endpoints with structured input (question and context), and retrieved predictions.
